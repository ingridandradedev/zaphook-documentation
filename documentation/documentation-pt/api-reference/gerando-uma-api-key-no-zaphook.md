# Gerando uma API Key no ZapHook

<figure><img src="../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

As **API Keys** permitem que sistemas externos se autentiquem e utilizem a API do ZapHook de forma segura. Com elas, é possível criar integrações, enviar e receber mensagens, gerenciar webhooks, consultar eventos, automatizar processos e conectar o ZapHook a plataformas como CRM, ERP, Power Automate, Microsoft 365, sistemas próprios e outras aplicações corporativas.

**Como criar uma API Key**

1. Acesse o menu **Configurações**.
2. Selecione a aba **Chaves de API**.
3. Clique no botão **Criar chave de API** localizado no canto superior direito da tela.
4. Informe um nome que identifique a finalidade da chave (por exemplo: Produção, CRM, Integração ERP ou Testes).
5. Confirme a criação da chave.
6. Copie a chave gerada e armazene-a em um local seguro.
